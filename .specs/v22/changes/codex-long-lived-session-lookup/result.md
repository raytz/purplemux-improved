## 审查后修正

独立静态审查指出：历史日期目录为符号链接时，`Dirent.isDirectory()` 不识别链接，导致回退搜索遗漏旧会话。已用临时目录复现，并改为对符号链接检查目标目录；年、月、日各级链接、失效链接和普通文件目标均有回归覆盖。

同次审查指出，未命中时每次会串行扫描历史日期目录，多年数据或慢存储可能放大延迟。此前本机未命中实测 86 ms，未测极端规模；本次不改变查找的实时性或增加缓存，该性能风险保留待进一步测量。

审查后重新运行上述六个测试文件共 71 项通过，完整 TypeScript、改动文件 ESLint 和 `pnpm build` 均通过。真实服务和浏览器未切换至本工作区，未进行实机验收。
