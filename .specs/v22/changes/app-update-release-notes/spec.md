# 在升级前查看目标版本的更新内容

用户原始需求：“升级的提示的时候有没有办法查看更新的功能点？”“请增加查看升级内容的能力”。

## 范围与行为

在 Purplemux 的工作区升级提示、设置页更新区和桌面端手动检查更新的弹窗中，为已检测到的新版本增加“查看更新内容”。说明来自本项目发布流程生成的 GitHub Release，按提示中的稳定版本匹配 `v<version>` 标签。网页版在新标签页打开，桌面端使用系统默认浏览器，用户可以回到工作区决定是否升级。

本次仅扩展基线中的升级提示。安装、跳过版本和重启仍由各自的操作触发。查看说明需要能访问 GitHub。

## 验收标准

1. 工作区和设置页显示目标版本的发布说明链接。没有可用的新稳定版本时隐藏链接。
2. 桌面检查更新弹窗展示相同目标版本的说明入口。查看操作不下载、不重启、不跳过版本。
3. 已跳过的版本继续隐藏工作区提示，设置页仍可查看说明。升级期间只读链接可用。
4. 入口使用界面语言，支持现有全部语言。原有升级操作的默认选项和取消行为保持原样。
