# 新建标签会话列表批量管理

## 原始需求

> 在这个地方的会话列表里支持批量管理会话吧

入口是工作区「＋」菜单中的 Claude 和 Codex 会话列表。用户可以搜索「无消息」，选中本次搜索结果，一次移除多条会话。

## 验收标准

- 桌面和移动选择器增加管理入口。普通模式点击恢复会话，管理模式点击勾选，支持全选当前搜索结果、取消选择及退出。改变搜索条件清空选择，以免误处理不可见会话。搜索支持界面显示的「无消息」。
- 确认页显示选中数量。沿用单项删除默认勾选原始记录的约定，允许取消勾选以仅移除 Purplemux 历史。取消确认不发送请求。
- 确认后按提供方和原生会话 ID 逐项执行既有删除流程，保留活动会话和子会话保护。执行期间复用工作区操作锁。部分失败显示数量和失败原因，成功项从列表消失，失败项保持勾选供重试。
- 搜索、应用启动、既有会话恢复和安装检查沿用选择器基线。以模拟数据覆盖筛选、确认、混合提供方、部分失败及重试，再做类型、静态及构建或浏览器检查。

见[任务记录](./task.md)和[实施与验证](./result.md)。
